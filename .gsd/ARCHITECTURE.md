## Data Flow

1. Developer inputs code inside the Frontend UI or a PR is created on GitHub.
2. The payload (code snippet) is sent via POST to the `/review` backend endpoint on AWS API Gateway.
3. API Gateway triggers the `reviewCode` Python Lambda function.
4. Lambda constructs a security context prompt and sends it to AWS Bedrock.
5. Claude 3.5 Sonnet returns a structured JSON containing severity, issue description, explanation, and a suggested fix.
6. Lambda returns the parsed JSON to the Frontend.
7. Frontend actively renders the original code alongside the suggested fix, explanation, and updates the overall security score.
